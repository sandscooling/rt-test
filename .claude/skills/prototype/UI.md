# UI prototype

Offered only while `scale.prototype_ui` is on. While it is off, `SKILL.md` offers the logic and output branches
alone.

**Turn it on** when the first `apps/*` editor workspace exists and a view-layout question arises that the
output branch cannot answer. Then rewrite this file for that workspace's views, keeping three rules from the
other branches: variants radically different on the axis the question asks, each promoted capture captioned
with **Take** and **Ignore**, and a residue check that finds anything the prototype left outside
`_agent-docs/.scratch/`.
